# Security policy

## Supported versions

Security fixes go to the latest release of `mongozod`. While it is in 0.x, update to the latest 0.x
version to get them.

## Reporting a vulnerability

Please report it privately instead of in a public issue, so that it isn't public before a fix is
released: [Report a vulnerability](https://github.com/tserdeiro/mongozod/security/advisories/new),
under the Security tab of the repository.

Include the version, a minimal reproduction and the impact you see. You'll get a first answer
within 7 days. When a fix is released, the advisory is published with credit to you, unless you
prefer otherwise.

## What MongoZod protects against

What the input builders guarantee, and what stays with your application, is in the
[security guide](https://mongozod.dev/docs/guides/security).
